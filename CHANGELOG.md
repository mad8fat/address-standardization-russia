# Changelog

## [1.0.0] — 2026-10-21

Первая публичная версия.

- Пять честных статусов вместо «Точный / Приблизительный»: «Подтверждён», «Город не указан», «Город не подтверждён», «Дом не найден», «Ошибка».
- Проверка привязки найденного населённого пункта к исходной строке и подсчёт городов-кандидатов (запрос десяти результатов вместо одного).
- Очистка хвостов «пом.», «кв.», «офис», «этаж», «литера» перед запросом к геокодеру.
- Поиск ограничен территорией России (`bbox` + `rspn=1`).
- Ключ API вводит пользователь, хранится в `localStorage`, в коде ключей нет.
- Режим «останавливаться только на сомнительных» и повторный проход по сомнительным после завершения.
- Карточка ручной проверки со списком кандидатов: клик заполняет поля.
- Колонки «Проверка» (авто / вручную) и «Кандидаты» в выгрузке.
- Экран исчерпанного лимита с продолжением по другому ключу.
- Тёмная тема по системной настройке.
- Тесты ядра в Node без сборки, проверка репозитория на секреты перед коммитом.
