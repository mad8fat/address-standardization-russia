# Changelog

## [1.0.0] — 2026-10-21

Первая публичная версия.

- Пять честных статусов вместо «Точный / Приблизительный»: «Подтверждён», «Город не указан», «Город не подтверждён», «Дом не найден», «Ошибка».
- Проверка привязки найденного населённого пункта к исходной строке и подсчёт городов-кандидатов (запрос десяти результатов вместо одного). Название улицы не может подтверждать одноимённый город или регион; одноимённые города в разных регионах требуют регион в строке.
- Для статуса «Город не указан» угаданный город в запись и выгрузку не попадает.
- Очистка сегментов «пом.», «кв.», «офис», «этаж», «литера» перед запросом к геокодеру с сохранением города, стоящего после них.
- Поиск ограничен территорией России (`bbox` + `rspn=1`), таймаут запроса 20 с, до трёх попыток.
- Ключ API вводит пользователь, хранится в `localStorage`, в коде ключей нет; поле ключа маскируется.
- Режим «останавливаться только на сомнительных», повторный проход по сомнительным, повтор адресов с ошибкой, продолжение после остановки или лимита.
- Карточка ручной проверки со списком кандидатов, проверкой координат и кнопкой «Остановить».
- Колонки «Проверка» (авто / вручную) и «Кандидаты» в выгрузке.
- Пауза после пяти сетевых ошибок подряд вместо «сжигания» списка статусом «Ошибка».
- Защита от загрузки новых данных во время обработки и от двойного запуска цикла.
- SheetJS 0.20.3 локально в `vendor/` (закрыты CVE старых версий на CDN), системные шрифты, Content-Security-Policy, ограничение размера файла и числа строк.
- Тёмная тема по системной настройке.
- Тесты ядра в Node без сборки; проверка индекса на секреты перед коммитом, включая UTF-16 и подмену библиотеки.
