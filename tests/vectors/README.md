# Тестовые векторы

Здесь лежат проверочные данные, не привязанные к языку программирования. Эталонная реализация ядра написана на JavaScript (`addr-core.js`), но те же файлы можно прогнать через реализацию на Python, Go, 1С или любом другом языке: если все кейсы дают тот же результат, реализация совместима.

Файлы бывают трёх видов. Файлы классификации (`confirmed.json`, `no-city.json` и любые другие, кроме двух перечисленных ниже) имеют вид `{ "description": "…", "cases": [ { "input": "…", "candidates": [Candidate…], "expected": { "status": "…", "anchor": "…" } } ] }`. Поле `anchor` в `expected` необязательно; для статуса «Дом не найден» оно равно `null`. Файл `tokenize.json` содержит `{ "cases": [ { "input": "…", "expected": ["…"] } ] }` (ожидаемый список слов), файл `clean.json` содержит `{ "cases": [ { "input": "…", "expected": "…" } ] }` (ожидаемая очищенная строка).

`Candidate` — это разобранный ответ геокодера, ровно с такими полями: `kind`, `precision`, `text`, `province` (массив строк), `area`, `locality`, `street`, `house`, `lat`, `lon`. Строки остаются строками, координаты — числами. Это тот же объект, который возвращает `parseGeocoderResponse`, поэтому реализации не нужно ходить в сеть: кандидаты уже записаны в вектор.

Чтобы прогнать свою реализацию, пройдите по всем кейсам. Для классификации: для каждого кейса вызовите свою `classify(input, candidates)` и сравните `status` и, если поле есть в `expected`, `anchor`. Для `tokenize.json` сравните результат `tokenize(input)` с `expected`, для `clean.json` — результат `cleanAddressForQuery(input)`. Псевдокод:

```
for case in vector.cases:
    got = classify(case.input, case.candidates)
    assert got.status == case.expected.status
    if "anchor" in case.expected: assert got.anchor == case.expected.anchor
```

Правило пополнения: добавляйте только публичные адреса (здания, которые и так известны всем) и реальные ответы геокодера, без выдуманных данных. Адреса клиентов, сотрудников и любые персональные сведения в векторы попадать не должны. JSON хранится с отступом в 2 пробела, в UTF-8 без BOM, с переводами строк LF и завершающим переводом строки.
